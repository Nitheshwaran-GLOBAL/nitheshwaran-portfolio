## GitHub upload

Create a NEW public repository under:
Nitheshwaran-GLOBAL

Suggested repository:
Nitheshwaran-Portfolio

Upload the ENTIRE contents of this folder, not just index.html.

The repository root must look like:
index.html
README.md
css/
js/
assets/

Then:
1. GitHub → Settings → Pages
2. Source → Deploy from a branch
3. Branch → main
4. Folder → / (root)
5. Save

Expected GitHub Pages URL:
https://nitheshwaran-global.github.io/Nitheshwaran-Portfolio/

## Important

Do not rename the folders.
Do not move index.html into another folder.
Keep the relative paths exactly as provided.
